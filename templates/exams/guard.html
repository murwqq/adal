{% translate "Расширение Адал Guard" %}

{% translate "Превращает обычный Chrome или Edge в браузер для экзамена. Включается само, когда начинается тест на Адал, и выключается после него." %}

{% blocktranslate trimmed %}Скачать, версия {{ version }}{% endblocktranslate %}

{% translate "Что делает во время теста" %}

  • {% translate "Браузер открывает только сайт Адал. Любые другие страницы показывают заглушку «Идёт тест»." %}
  • {% translate "ChatGPT, Gemini, Claude, DeepSeek, Copilot, Perplexity и сайты с готовыми ответами заблокированы. Попытка открыть их считается нарушением и видна преподавателю." %}
  • {% translate "Новые вкладки и окна закрываются сразу, вкладки, открытые до теста, закрываются при его начале." %}
  • {% translate "Если в браузере включены ИИ-расширения (помощники в боковой панели), преподаватель видит их названия." %}
  • {% translate "Если расширение отключить во время теста, это тоже фиксируется." %}

{% translate "Чего не делает" %}

  • {% translate "Не работает вне экзамена: в обычное время браузер ведёт себя как всегда." %}
  • {% translate "Не видит экран, камеру и микрофон, не читает историю, пароли и содержимое других сайтов." %}
  • {% translate "Никуда не отправляет данные: события передаются только странице теста на Адал." %}

{% translate "Как установить" %}

  1. {% translate "Скачайте архив и распакуйте его в любую папку." %}
  2. {% translate "Откройте в браузере страницу chrome://extensions (в Edge: edge://extensions)." %}
  3. {% translate "Включите «Режим разработчика» в правом верхнем углу." %}
  4. {% translate "Нажмите «Загрузить распакованное расширение» и выберите папку adal-guard." %}

{% translate "Для компьютерных классов" %}

{% translate "Администратор может установить расширение на все компьютеры аудитории через групповые политики Chrome (ExtensionInstallForcelist) и запретить режим инкогнито (IncognitoModeAvailability = 1). Тогда студент не сможет отключить его перед тестом." %}

{% translate "Для преподавателя" %}

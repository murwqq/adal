# 5. Описание маршрутов

Обозначения прав: **Все** — без входа; **Вошедший** — любой авторизованный; **Студент-владелец** —
только автор попытки; **Преподаватель** — роль teacher/admin; **Автор теста** — преподаватель,
создавший тест (или суперпользователь). Все POST-запросы требуют CSRF-токен.

## Учётные записи

| URL | Метод | Права | Назначение |
|---|---|---|---|
| `/accounts/login/` | GET, POST | Все | Вход по ИИН и паролю; блокировка после 5 ошибок |
| `/accounts/logout/` | POST | Вошедший | Выход |
| `/accounts/register/` | GET, POST | Все | Регистрация абитуриента |
| `/accounts/captcha.png` | GET | Все | Картинка капчи (код хранится в сессии) |
| `/accounts/rules/` | GET | Все | Пользовательское соглашение |
| `/i18n/setlang/` | POST | Все | Смена языка интерфейса (kk/ru/en) |

## Главная и банк вопросов

| URL | Метод | Права | Назначение |
|---|---|---|---|
| `/` | GET | Вошедший | Кабинет студента или преподавателя |
| `/subjects/new/` | POST | Преподаватель | Добавить дисциплину |
| `/bank/` | GET | Преподаватель | Банк: `q`, `subject`, `topic`, `difficulty`, `mine`, `sort`, `page` |
| `/bank/new/` | GET, POST | Преподаватель | Новый вопрос |
| `/bank/<id>/` | GET, POST | Преподаватель | Изменить вопрос |
| `/bank/<id>/delete/` | POST | Преподаватель | Удалить (или скрыть, если использован) |
| `/bank/import/` | GET, POST | Преподаватель | Загрузка .docx/.txt |

## Тесты (преподаватель)

| URL | Метод | Права | Назначение |
|---|---|---|---|
| `/exams/` | GET | Преподаватель | Мои тесты |
| `/exams/new/`, `/exams/<id>/edit/` | GET, POST | Автор теста | Создание и настройка |
| `/exams/<id>/results/` | GET | Автор теста | Результаты: `q`, `group`, `status`, `flagged`, `sort`; `export=csv` |
| `/exams/<id>/analysis/` | GET | Автор теста | Анализ вопросов |
| `/exams/<id>/monitor/` | GET | Автор теста | Наблюдение |
| `/exams/<id>/monitor/data/` | GET | Автор теста | JSON для наблюдения |
| `/attempts/<id>/` | GET | Автор теста | Ответы и нарушения студента |
| `/attempts/<id>/manage/` | POST | Автор теста | `action=resume` — разрешить продолжить; `action=stop` — остановить |

## Прохождение (студент)

| URL | Метод | Права | Назначение |
|---|---|---|---|
| `/exams/<id>/start/` | GET, POST | Вошедший | Правила и ввод кода доступа |
| `/attempt/<id>/` | GET | Студент-владелец | Экран теста |
| `/attempt/<id>/q/<n>/` | GET | Студент-владелец | HTML-фрагмент вопроса n |
| `/attempt/<id>/answer/` | POST (JSON) | Студент-владелец | `{position, choice}` → сохранить ответ |
| `/attempt/<id>/event/` | POST (JSON) | Студент-владелец | `{kind}` → записать нарушение |
| `/attempt/<id>/ping/` | POST | Студент-владелец | Пульс: сверка времени и статуса |
| `/attempt/<id>/finish/` | POST | Студент-владелец | Завершить попытку |
| `/attempt/<id>/result/` | GET | Студент-владелец | Результат |

## Администрирование

| URL | Метод | Права | Назначение |
|---|---|---|---|
| `/admin/` | GET, POST | Суперпользователь | Пользователи, роли, все данные |

# 11. Чек-лист безопасности

| № | Проверка | Где реализовано | Статус |
|---|---|---|---|
| 1 | Запросы к БД параметризованы, нет конкатенации SQL | Django ORM во всех модулях; сырого SQL нет | ✔ |
| 2 | Пароли хранятся хешем | `AbstractBaseUser.set_password` (PBKDF2) | ✔ |
| 3 | Проверка сложности пароля | `AUTH_PASSWORD_VALIDATORS`: длина ≥ 8, не распространённый, не только цифры | ✔ |
| 4 | CSRF-токен во всех изменяющих формах и AJAX | `CsrfViewMiddleware`, `{% csrf_token %}`, заголовок `X-CSRFToken` в `exam.js` | ✔ |
| 5 | GET-запросы не меняют данные | Изменения только через `@require_POST` / POST-формы | ✔ |
| 6 | Экранирование вывода (XSS) | Автоэкранирование шаблонов; `|safe` не используется; JS-строки через `escapejs` | ✔ |
| 7 | Защита от перебора паролей | 5 попыток → блокировка ИИН на 10 мин (`accounts/views.py`) | ✔ |
| 8 | Капча при регистрации | `accounts/captcha.py`, одна картинка — одна попытка | ✔ |
| 9 | Проверка прав на каждом представлении | `teacher_required`, `_own_exam`, `_student_attempt` → 403 | ✔ (тесты TC-08, TC-09) |
| 10 | Нет открытого редиректа | `url_has_allowed_host_and_scheme` для `next` | ✔ (TC-07) |
| 11 | Секретный ключ не в коде для продакшена | `DJANGO_SECRET_KEY` из окружения | ✔ (задать на сервере) |
| 12 | `DEBUG` выключен в продакшене | `DJANGO_DEBUG=0` | ✔ (задать на сервере) |
| 13 | Cookie Secure и HttpOnly | `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE` при `DEBUG=0` | ✔ |
| 14 | Запрет встраивания во фреймы | `X_FRAME_OPTIONS = "DENY"` | ✔ |
| 15 | Ограничение загружаемых файлов | Только .docx/.txt до 10 МБ; картинки перекодируются Pillow | ✔ |
| 16 | Сравнение кодов в постоянном времени | `secrets.compare_digest` для капчи и кода доступа | ✔ |
| 17 | Маскирование персональных данных на экране | ИИН показывается как 0401••••••37 | ✔ |
| 18 | Резервное копирование | Ежедневная копия `db.sqlite3` и `media/` | Настроить на сервере |
| 19 | HTTPS | nginx с сертификатом | Настроить на сервере |
| 20 | Нет секретов в репозитории | `.gitignore`: `.env`, `db.sqlite3`, `media/` | ✔ |

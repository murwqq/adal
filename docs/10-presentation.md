# 10. Презентация для защиты (9 слайдов)

Структура по пособию: проблема → решение → архитектура → демонстрация → тесты → безопасность →
итог. На каждом слайде — одна мысль, текста минимум, остальное — устно.

---

### Слайд 1. Название
**Адал — честное тестирование**
Платформа тестирования студентов с таймером. Вариант 9.
ФИО, группа, руководитель, 2026.

---

### Слайд 2. Проблема
Две фотографии/скриншота рядом:
* тест из Word, где правильный ответ выделен жирным, и мутная формула-картинка;
* браузер с вкладкой ChatGPT рядом с вкладкой теста.

Подпись: «Студент угадывает по оформлению. Студент спрашивает ИИ. Система этого не видит».

---

### Слайд 3. Решение
Три коротких пункта:
1. Оформление из Word срезается, формулы становятся чёткими — файлы переписывать не нужно.
2. Свой вариант у каждого, таймер на сервере.
3. Уход с теста фиксируется и виден преподавателю в реальном времени.

Скриншот: `screens/08-import.jpg` с предупреждением «правильный ответ был выделен».

---

### Слайд 4. Архитектура
Схема «Интерфейс → Бизнес-логика → Хранение» из [архитектуры](03-architecture.md#32-слои-и-компоненты).
Подпись: «Логика не знает о вебе — её можно подключить к настольной или мобильной версии».

---

### Слайд 5. Демонстрация: студент
Живая демонстрация (или скриншоты 04a → 04b → 04c):
код доступа → полноэкранный тест → переключение вкладки → экран «Вы покинули тест» → результат.

---

### Слайд 6. Демонстрация: преподаватель
Скриншоты `12-monitor.jpg` и `10-analysis.jpg`.
«Наблюдение» в реальном времени; анализ вопросов: «вероятно, ошибка в ключе».
Поиск «ПРОИЗВОДНАЯ» находит «Производная» — фильтры и сортировка (усложнение варианта).

---

### Слайд 7. Тесты
* 84 автотеста, все проходят
* Покрытие 92 %, бизнес-логика — 98 %
* Граничные случаи: ответ на 2-й и 6-й секунде после дедлайна, тест, закрывающийся раньше
  окончания времени, повреждённый .docx

---

### Слайд 8. Безопасность
Пароли — хеш · CSRF · ORM без SQL-инъекций · проверка прав на каждом запросе ·
блокировка перебора · капча · секреты в переменных окружения.

# 6. План и отчёт тестирования

## 6.1 Подход

* **Модульные тесты** чистой логики: `iin.py`, `analysis.py`, `importer.py`, `build_variant`.
* **Тесты бизнес-логики с БД**: `services.py` на временной базе (pytest-django).
* **Тесты веб-слоя** через тестовый клиент Django — запросы без запуска сервера.
* **Ручные проверки** в браузере: полноэкранный режим, фиксация ухода со вкладки, KaTeX.
* Каждая группа проверяет нормальный случай, граничный случай и ошибку (раздел 5.5 пособия).

Запуск: `python -m pytest`; покрытие: `python -m coverage run --source=accounts,exams -m pytest`,
затем `python -m coverage report`.

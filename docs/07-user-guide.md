# 7. Руководство пользователя

## 7.1 Назначение и требования

«Адал» — платформа для проведения тестов в компьютерных аудиториях. Нужен любой современный
браузер (Chrome, Edge, Firefox, Яндекс Браузер) последних двух лет. Для формул и шрифтов нужен
доступ в интернет. Установка на компьютеры студентов не требуется.

Язык интерфейса переключается кнопками **Қаз / Рус / Eng** в правом верхнем углу любой страницы.

## 7.2 Вход и регистрация

**Вход.** Введите ИИН (12 цифр) и пароль, нажмите «Войти». После пяти неверных паролей вход
блокируется на 10 минут. Забытый пароль сбрасывает офис регистратора.

**Регистрация абитуриента.** Нажмите «Создать аккаунт абитуриента» и пройдите три шага:
1. *Поступление* — гражданство, степень, язык обучения, форма поступления.
2. *Личные данные* — ИИН (под полем сразу появится дата рождения; если появилось
   «Контрольная цифра не совпадает» — в номере опечатка), ФИО, почта, документ.
3. *Пароль* — пароль дважды, символы с картинки (кнопка ⟳ показывает другую), согласие с
   соглашением. Нажмите «Создать аккаунт».

Учётные записи преподавателей создаёт администратор.

## 7.3 Студент: как пройти тест

1. На странице «Мои тесты» нажмите «Перейти к тесту».
2. Прочитайте правила, введите **код доступа** — его называет преподаватель — и нажмите
   «Начать тест». Начать можно только один раз.
3. Нажмите «Начать»: тест откроется во весь экран.
4. Выберите ответ — он сохраняется сразу (внизу появится «Ответ сохранён»). Переходите
   кнопками «Следующий вопрос» или по номерам слева: закрашенный номер = есть ответ.
5. Таймер справа сверху становится жёлтым за 5 минут и красным за 1 минуту. Когда время
   закончится, тест завершится сам.
6. Нажмите «Завершить тест» → «Завершить и узнать результат».

**Что считается нарушением:** переключение на другую вкладку или программу, выход из
полноэкранного режима (Esc), правая кнопка мыши, копирование и вставка, F12, Print Screen.
После каждого нарушения экран блокируется до нажатия «Вернуться к тесту», красные точки в
верхней строке показывают число нарушений. После лимита (обычно 3) тест завершается, баллы
считаются по уже выбранным ответам.

**Компьютер завис?** Поднимите руку. Преподаватель нажмёт «Разрешить продолжить в другом
браузере», вы войдёте с другого компьютера — все выбранные ответы сохранены.

## 7.4 Преподаватель

### Добавить вопросы
* **Из Word.** «Банк вопросов» → «Загрузить из Word». Файл в формате Platonus:
  ```
  <topic>Производная          ← необязательно, тема для следующих вопросов
  <question>Производная функции $x^2$ равна
  <variant>$2x$               ← первый вариант — правильный
  <variant>$x$
  <variant>$x^3/3$
  ```
  Отметьте «Только проверить», чтобы сначала увидеть замечания. Платформа сама уберёт жирный,
  курсив и цвет, переведёт формулы редактора формул Word, уберёт нумерацию «А)», «1.».
* **Вручную.** «Добавить вопрос». Формулы пишите между `$…$` или нажимайте кнопки «Дробь»,
  «Корень», «Интеграл»… Блок «Так увидит студент» показывает результат. Отметьте кружок
  у правильного варианта.

### Найти вопрос
Поиск ищет по тексту вопросов и вариантов, регистр не важен. Фильтры: дисциплина, тема,
сложность, «Только мои вопросы». Сортировка «Хуже всего решают» показывает вопросы, которые
студенты чаще всего решают неверно.

### Создать тест
«Создать тест»: название, дисциплина, (необязательно) тема, число вопросов в варианте, время,
окно открытия, группы через запятую. В блоке «Защита от списывания» задайте код доступа,
число нарушений до завершения, сеть аудитории (например, `10.12.5.`) и разрешите ли разбор
после теста. Если вопросов в банке меньше, чем нужно, платформа предупредит.

### Во время теста
Вкладка «Наблюдение» обновляется каждые 5 секунд: сколько ответил каждый студент, сколько
осталось времени, нарушения (последнее — подписью), «Нет связи» — страница закрыта или
компьютер отключён. «Подробнее» → ответы студента и действия «Разрешить продолжить» /
«Остановить попытку».

### После теста
* «Результаты» — средний балл, медиана, разброс, гистограмма; поиск по ФИО или началу ИИН;
  фильтры по группе, статусу, «Только с нарушениями»; сортировка; «Скачать CSV» для Excel.
* «Анализ вопросов» — для каждого вопроса трудность (доля верных), различение (насколько
  чаще верно отвечают сильные студенты) и доли выбора вариантов. Замечания подскажут, что
  исправить: «Слишком лёгкий», «вероятно, ошибка в ключе», «неработающие варианты».

## 7.5 Сообщения об ошибках

| Сообщение | Что делать |
|---|---|
| Неверный ИИН или пароль | Проверьте раскладку и Caps Lock |
| Слишком много неудачных попыток | Подождите 10 минут |
| Неверный код доступа | Уточните код у преподавателя |
| Этот тест назначен другой группе | Проверьте группу в профиле, обратитесь в деканат |
| Тест можно проходить только с компьютеров учебной аудитории | Пересядьте за компьютер аудитории |
| Тест уже открыт в другом браузере | Попросите преподавателя разрешить продолжить |
| Нет связи с сервером — выберите ответ ещё раз | Проверьте сеть и выберите ответ снова |
| В банке N подходящих вопросов, а нужно M | Добавьте вопросы или уменьшите число вопросов в тесте |
| Должен быть ровно один правильный ответ | Отметьте один вариант правильным |
